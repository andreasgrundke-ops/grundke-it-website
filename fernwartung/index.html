Fernwartung starten

Ich schalte mich direkt auf deinen Rechner und löse das Problem, während du zusiehst. Wähl unten dein System, dann führt dich die Anleitung Schritt für Schritt.

Welches System läuft auf deinem Rechner?

Passend zu deinem Gerät vorausgewählt.

Fernwartung herunterladen

Windows 10 / 11 Anleitung Schritt für Schritt Richtet den Zugang selbst ein

So geht's unter Windows

  1. Programm herunterladen

    Klick oben auf den Knopf. Die Datei landet in deinem Downloads-Ordner.

    Der Browser meldet „Verdächtiger Download blockiert"?
    Das ist normal – die Datei ist noch nicht signiert. Klick auf „Trotzdem herunterladen" (Chrome / Edge) beziehungsweise „Datei behalten" (Firefox).

  2. Programm starten

    Öffne die heruntergeladene Datei per Doppelklick – direkt aus dem Downloads-Ordner.

    „Der Computer wurde durch Windows geschützt"?
    Auch das ist normal. So geht es weiter:
    1. Auf „Weitere Informationen" klicken
    2. Dann auf „Trotzdem ausführen" klicken

    Die offizielle Code-Signierung folgt – dann entfällt diese Meldung.

  3. Windows-Rückfrage mit „Ja" bestätigen

    Windows fragt einmal nach, ob das Programm Änderungen vornehmen darf. Bitte auf „Ja" klicken – danach läuft alles von selbst.

    Warum ist das nötig?
    Damit richtet sich der Zugang sauber ein. Ohne diese Bestätigung müsstest du bei jeder Verbindung erneut zustimmen und mir ein Kennwort vorlesen.

  4. Fertig – ich übernehme

    Ein kleines Fenster meldet „Verbindung steht". Lass es einfach offen, du kannst es nach unten minimieren. Über „Fernwartung beenden" beendest du die Sitzung jederzeit selbst.

Fernwartung für Linux herunterladen

Linux Mint, Ubuntu, Debian 64-Bit ca. 26 MB

So geht's unter Linux

  1. Programm herunterladen

    Klick oben auf den Knopf. Die Datei grundke-support-linux-amd64 landet in deinem Downloads-Ordner.

  2. Im Terminal starten

    Öffne das Terminal mit Strg + Alt + T, füge diese Zeile ein und drück Enter:

    cd ~/Downloads && chmod +x grundke-support-linux-amd64 && ./grundke-support-linux-amd64

    Die Zeile macht die Datei startbar und führt sie aus.

  3. Mit deinem Passwort bestätigen

    Das System fragt einmal nach deinem Passwort, damit sich die Fernwartung einrichten kann. Es ist dasselbe, mit dem du dich am Rechner anmeldest.

  4. Fertig – ich übernehme

    Ein kleines Fenster meldet „Verbindung steht". Lass es einfach offen. Die Fernwartung bleibt danach für den laufenden Support installiert.

    Ich sehe deinen Bildschirm nicht?
    Linux Mint startet von Haus aus passend. Ubuntu und Debian melden dich oft mit Wayland an, dann bleibt mein Bild schwarz. So stellst du um:
    1. Abmelden
    2. Am Anmeldebildschirm auf das Zahnrad unten rechts klicken
    3. „Ubuntu on Xorg" bzw. „GNOME on Xorg" wählen und wieder anmelden

    Neuere Ubuntu-Versionen (ab 25.10) bieten diesen Eintrag nicht mehr an. Dann ruf mich kurz an.

Neu: noch in Erprobung

Am Mac richten wir die Fernwartung beim ersten Mal zusammen am Telefon ein. Die Vorbereitung kannst du schon selbst machen.

RustDesk für macOS herunterladen

Offizielle Seite von RustDesk Datei endet auf .dmg

So geht's am Mac

  1. Die passende Datei laden

    Auf der Seite von RustDesk stehen unter „Assets" mehrere Dateien. Du brauchst die mit .dmg am Ende:

    • Mac mit Apple-Chip (M1 und neuer): Datei mit aarch64 im Namen
    • Älterer Mac mit Intel-Prozessor: Datei mit x86_64 im Namen

    Welchen Chip du hast, steht unter Apple-Menü → Über diesen Mac.

  2. Installieren und einmal öffnen

    Doppelklick auf die geladene Datei, dann RustDesk in den Ordner „Programme" ziehen. Danach RustDesk aus „Programme" starten. Fragt der Mac nach, ob du es wirklich öffnen willst: „Öffnen".

  3. Zwei Freigaben einschalten

    Unter Systemeinstellungen → Datenschutz & Sicherheit RustDesk an zwei Stellen einschalten:

    • Bildschirmaufnahme (ab macOS 15: „Bildschirm- und Systemaudioaufnahme")
    • Bedienungshilfen
    Warum ist das nötig?
    Ohne die erste Freigabe sehe ich deinen Bildschirm nicht, ohne die zweite kann ich nichts anklicken. Diese Schalter kann nur jemand am Mac selbst umlegen.

  4. Anrufen – den Rest mache ich

    Ruf mich an. Ich verbinde RustDesk mit meinem Server und richte den Zugang ein. Dafür bekommst du von mir eine Zeile fürs Terminal mit deinem persönlichen Link.
