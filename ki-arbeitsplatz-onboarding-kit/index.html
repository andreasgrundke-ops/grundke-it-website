Was das hier ist

Ein Arbeitsbuch, kein Handbuch. Es bringt Sie von null auf arbeitsfähig — Konto, Rechner, Struktur, Claude Code, und am Ende die ersten echten Aufgaben. Zwölf Phasen, jeder Punkt zum Abhaken; der Stand bleibt in diesem Browser gespeichert, auch wenn Sie zwischendurch schließen.

Von oben nach unten durcharbeiten. Die Reihenfolge ist nicht beliebig: Phase 0 entscheidet, welche Daten überhaupt angefasst werden dürfen, und Phase 3 legt fest, wie Claude arbeitet — beides wirkt auf alles Spätere. Phase 4 (Design-System) steht bewusst früh, damit alle späteren Oberflächen und Dokumente von Anfang an gleich aussehen.

Legende: Pflicht muss sitzen, bevor es weitergeht · Optional nach Bedarf · Später bewusst auf einen zweiten Durchgang verschoben.

Die Vorlagen, Muster-Dateien und fertigen Skills, auf die die Phasen verweisen, stehen weiter unten unter Material zum Herunterladen.

Material zum Herunterladen

Alle Vorlagen, auf die die Phasen verweisen — Textbausteine zum Kopieren, zwei fertige Projektvorlagen, zwölf einsatzbereite Skills und die Konnektoren-Checkliste. Einmal alles als Paket, oder einzeln.

Persönliche Anweisungen Vorlage für „Instructions for Claude" — Phase 3 Markdown CLAUDE.md in drei Ebenen Global, Projekt, Baustein — Phase 5 Markdown Projektvorlagen Privat und Beruf, je Anweisung und CLAUDE.md — Phase 5 ZIP Zwölf Skills Fertig zum Hochladen, je eine ZIP — Phase 6 ZIP Konnektoren-Checkliste Nachweis, was verbunden ist und wer freigegeben hat — Phase 7 Markdown Alle Langfassungen Elf Anleitungen inklusive Lernkarten und Datenschutz ZIP

Wenn etwas klemmt

Die drei häufigsten Stolperstellen stehen in den Phasen selbst: Code Execution nicht eingeschaltet (dann sind Skills unsichtbar), ANTHROPIC_API_KEY noch in der Shell (dann wird nach Verbrauch statt über das Abo abgerechnet), und die Annahme, die VS-Code-Erweiterung ersetze die Kommandozeile (tut sie nicht).

Alles andere: melden Sie sich. Rückmeldungen fließen in die nächste Fassung dieses Arbeitsbuchs ein.
